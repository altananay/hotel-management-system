# Sözleşme Artefaktları (`contracts/`)

Bu dizin, uygulamalar arası API sözleşme artefaktlarını (OpenAPI şemaları ve üretilen istemci sözleşmeleri) barındırır.

- İlk kurulum diliminde (`specs/0001-project-architecture.md`) dizin yapısı ayrılmıştır.
- İş modüllerinin REST uçları eklendikçe OpenAPI sözleşmeleri bu dizin altında versiyonlanır (`docs/architecture.md` §10 D14, `docs/frontend.md`).
